Carve support for JetBrains IDEs, with highlighting, preview, and optional language server features. Plugin version 0.1.18 targets JetBrains IDE 2025.1 and later. See the [Carve documentation](https://markup-carve.github.io/carve/) for the markup language.

## Features

- Syntax highlighting and live preview.
- Import and export commands.
- Optional diagnostics, completion, and navigation through LSP4IJ.

## Install

Install [Carve from JetBrains Marketplace](https://plugins.jetbrains.com/plugin/32204-carve). Install LSP4IJ to enable language server features.

## Usage

Open a `.crv` file to edit beside its live preview.
